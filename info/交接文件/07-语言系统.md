# 语言系统

更新时间：2026-07-13

## 主插件语言

- 管理类：`LanguageManager`。
- 资源：`src/main/resources/lang/zh_CN.yml`、`en_US.yml`。
- 运行目录：`plugins/KaGameCenter/lang/`。
- 配置：`config.yml` 的 `language`。

主插件语言只保存命令、房间、观战、菜单、数据库、跨服和通用显示文案。缺少 key 时回退内置资源，再缺失则返回 key 并记录 warning。

## 模块私有语言

- 类：`ModuleLanguage`。
- jar 资源：`lang/*.yml`。
- 运行目录：`plugins/KaGameCenter/modules/<module>/lang/`。
- 模块 jar 首次加载时只释放缺失文件，不覆盖管理员修改。
- 每个键按“外部当前语言 → JAR 内当前语言 → 外部英文 → JAR 内英文 → 主插件语言”回退。

玩法角色、道具、阶段、结算和编辑器文案必须放模块语言文件，不能写进主插件语言资源。

模块传入的资源目录是 `lang`，实际 JAR 路径为 `lang/<locale>.yml`。`ModuleLanguage` 不把新增键写回管理员文件；旧文件缺键时直接读取当前模块 JAR 的内置值，因此升级不会覆盖定制，也不会因未手工合并新键而显示键名。字符串和字符串列表都使用相同的逐层优先级；`getMessage` 会用换行拼接列表，`getMessageList` 会把既有标量兼容为单元素列表。外部文件中的空字符串或空列表仍视为显式配置，不会被内置值替换。

## 模块用法

```kotlin
val language = ModuleLanguage(
    context.plugin,
    context.languageManager,
    context.dataFolder,
    "lang"
) { path -> javaClass.classLoader.getResourceAsStream(path) }
language.reload()
```

普通文案调用 `getMessage(key, args)`；多行显示调用 `getMessageList(key, args)`。列表中的每项仍独立执行 `{0}`、`{1}` 数字参数替换，具体显示服务再决定如何拼行或解释动画语法。

通过 `RoomBroadcastService.localized(...)` 可以向当前房间广播模块语言文本。

## 当前限制

- `/kgc reload lang` 只重载主插件语言；模块私有语言随 `/kgc reload model <moduleId|all>` 重新加载，因此会同时关闭目标模块活动房间。
- 尚未提供不卸载模块、只刷新模块私有语言的轻量命令。
- 不会把新增 key 物理合并到管理员文件；运行时由 JAR 内置资源补齐。
- MiniMessage 解析由具体显示/菜单服务决定，`LanguageManager.getMessage` 本身返回字符串。
- 当前语言是服务器级配置，不保存逐玩家偏好。玩家语言切换事件必须同时具备语言持久化、切换命令和所有单发/广播/Sidebar 的逐受众渲染；在这些能力完整落地前不要添加无法改变实际文案的事件外壳。
