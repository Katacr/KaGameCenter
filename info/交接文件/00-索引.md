# 交接文件索引

- `01-项目概况.md`：当前项目、版本、模块和架构边界。

- `05-玩家数据统计.md`：SQLite/MySQL 基础统计和统一结果服务。
- `06-模块文档约定.md`：主插件、模块、wiki 和交接文档的职责边界。
- `07-语言系统.md`：主插件与模块私有 i18n。
- `08-游戏管理类.md`：模块、定义、托管游戏和地图目录。
- `09-Parkour组件.md`：跑酷模块当前实现摘要。
- `10-KaMenu动态菜单接入.md`：KaMenu YAML、动态 TYPE 和动作命名空间。
- `11-PacketEvents发包层与游戏前置插件.md`：发包抽象、伪装、发光和私有视觉。
- `12-模块生命周期与数据持久化.md`：模块卸载、资源释放和数据库。
- `13-菜单模板与动态按钮TYPE.md`：持久化菜单模板与动态节点。

- `16-Blockhunt方块躲猫猫模块.md`：躲猫猫角色、伪装、锁定和道具。
- `17-局内聊天系统.md`：队伍、房间和本服全局聊天。
- `18-GameCenter通用基底API.md`：可供所有模块复用的主插件服务。
- `19-箱子菜单基底.md`：内置箱子菜单模板、动作和动态数据源。
- `20-玩家名牌服务.md`：按房间控制玩家名牌和生命周期清理。

## 维护规则

- 不在交接文档保留已经删除的命令、目录和测试状态。
- 历史原因只在解释当前约束时保留，不写时间线流水账。
- 新增主插件服务时同步更新 `18` 和对应 wiki 专题。
- 模块玩法变化写入模块自己的技术细节，不在主插件文档复制完整规则。
