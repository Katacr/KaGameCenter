# 项目概况

更新时间：2026-07-13

## 项目

- 名称：`KaGameCenter`。
- 源码：`/home/plugins/KaGameCenter`。
- 编译目标：Paper API `1.21.11`，Java/Kotlin toolchain 21。
- 测试服：Paper `26.2`，目录 `/home/minecraft/Paper26.2`。
- 类型：主插件 + 托管小游戏模块。

## 当前模块

- `parkour`：跑酷。
- `blockhunt`：方块躲猫猫。
- `tntwars`：TNT Wars。
- `hunger`：饥饿游戏源码模块。

模块 jar 位于 `plugins/KaGameCenter/modules/<id>.jar`，不放在 Bukkit 插件根目录，也不包含 `plugin.yml`。

## 当前能力

- 多模块、多房间和独立 session。
- 托管游戏配置、公共模板、私有地图快照和临时运行世界。
- 玩家/观战者身份、队伍、聊天和状态恢复。
- 菜单、计分板、BossBar、Title、ActionBar、Tab 和名牌。
- SQLite/MySQL 基础统计。
- PacketEvents 私有视觉和伪装抽象。
- Redis/Velocity 房间摘要、reservation 和 join intent。
- 模块自动扫描、资源释放和卸载清理。
