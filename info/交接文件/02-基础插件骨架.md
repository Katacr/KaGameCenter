# 基础插件骨架

更新时间：2026-07-13

## 入口

- 主类：`src/main/kotlin/org/katacr/kaGameCenter/KaGameCenter.kt`。
- 插件声明：`src/main/resources/plugin.yml`。
- 主命令：`/kagamecenter`，别名 `/kgc`。
- 聊天命令：`/a`、`/g`。
- 权限：`kagamecenter.user`、`kagamecenter.admin`、`kagamecenter.chat.spy`。

## 依赖

运行时由 BukkitLibraryManager 加载：

- Kotlin stdlib
- SQLite JDBC
- MySQL Connector/J
- HikariCP
- Gson
- Lettuce

软依赖：

- KaMenu
- PlaceholderAPI
- Multiverse-Core
- WorldEdit
- PacketEvents

KaMenu 和 PacketEvents 不可用时主插件仍能启动；依赖这些能力的模块应在 `GameDefinition.requiredPlugins` 中声明。

## 初始化顺序

1. 保存默认配置并初始化主语言。
2. 初始化队伍、PacketEvents 后端、名牌、选区、观战和显示服务。
3. 初始化游戏注册、地图、临时世界、托管游戏和编辑器。
4. 初始化统计、跨服桥、房间、聊天和菜单。
5. 自动加载模块，再加载托管游戏目录。
6. 启动房间 tick、跨服处理、菜单和监听器。

关闭顺序负责停止菜单、房间和模块，保存编辑会话，清理任务、实体、名牌、发包视觉、跨服连接和数据库。

## 构建

```bash
cd /home/plugins/KaGameCenter
bash ./gradlew compileKotlin
bash ./gradlew shadowJar
```

主产物：`build/libs/KaGameCenter-1.0.0.jar`。

测试服部署到 `/home/minecraft/Paper26.2/plugins/`，具体操作见 `../wiki/10-构建部署与验收.md`。

## 菜单入口

`GameCenterMenuService` 生成当前上下文的 YAML：

1. 优先调用 KaMenu `openConfig`。
2. KaMenu 不可用时尝试内置箱子菜单兼容层。
3. 两者均失败时使用 Paper Dialog 主菜单兜底。

`kgc:` 动作最终回到主插件统一房间/地图/管理逻辑。
