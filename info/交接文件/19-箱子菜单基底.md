# 箱子菜单基底

更新时间：2026-07-13

## 定位

内置箱子菜单适合物品选择、职业/队伍选择和频繁点击操作。当前主流程仍优先使用 KaMenu，因为它更适合大量文本、下拉选择和输入框；KaMenu 不可用时，`openExternalConfig` 会尝试箱子菜单兼容层。

## 组成

包：`org.katacr.kaGameCenter.menu.chest`

- `ChestMenuService`：加载、打开、渲染和刷新。
- `ChestMenuTemplateService`：释放和读取模板。
- `ChestMenuHolder`：保存布局、页码、上下文和槽位变量。
- `ChestMenuListener`：点击、拖拽、关闭和退出处理。
- `ChestMenuActionRouter`：解析动作。
- `ChestMenuItemBuilder`：构造显示物品。
- `ChestMenuDataSourceRegistry`：模块动态条目。

模板目录：

```text
plugins/KaGameCenter/chest-menus/*.yml
```

## YAML

```yaml
title: "&0游戏中心"
update: 20
layout:
  - "#########"
  - "#   C   #"
  - "#   R   #"
  - "#########"
buttons:
  "#":
    display:
      material: GRAY_STAINED_GLASS_PANE
      name: " "
  "C":
    display:
      material: LIME_DYE
      name: "&a创建房间"
    actions:
      left:
        - "kgc:open-create-game"
```

显示支持 material、name、lore、amount、enchanted、potion-display、potion-color、custom_data、item_model、颜色、MiniMessage、物品图标、玩家头像和变量。

## 动作

- 点击：`left/right/shift_left/shift_right/drop`。
- 导航：`open/close/update/PAGE_NEXT/PAGE_PREV`。
- 输出：`tell/message/sound`。
- 命令：`command/console`。
- 主插件动作：`kgc:<payload>`。
- 条件：`&&`、`||`、比较运算和 PlaceholderAPI 预解析。

## 动态数据源

模块通过：

```kotlin
context.registerChestMenuDataSource("players", source)
```

注册后名称自动变为 `<moduleId>:players`，卸载时自动注销。每个动态槽位保存独立变量，点击不会串到其他玩家或房间。

## 当前限制

- 箱子菜单不能原生承载 KaMenu 的下拉与文本输入体验。
- 模块私有 `chest-menus/` 尚未由模块加载器自动释放。
- 头颅皮肤、通用 hide flags 和 PDC 仍可继续增强。
