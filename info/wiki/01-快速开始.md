# 01 快速开始

更新时间：2026-07-13

本章创建一个最小 `example` 模块：可被主插件加载、可创建房间、可加载地图并接收玩家加入事件。

## 1. 创建源码目录

```text
modules/example/
  build.gradle.kts
  src/main/kotlin/org/example/kagame/ExampleModuleProvider.kt
  src/main/kotlin/org/example/kagame/ExampleGameModule.kt
  src/main/kotlin/org/example/kagame/ExampleGameSession.kt
  src/main/resources/config.yml
  src/main/resources/lang/zh_CN.yml
  src/main/resources/lang/en_US.yml
```

在根 `settings.gradle.kts` 添加：

```kotlin
include("modules:example")
```

## 2. Gradle 配置

```kotlin
plugins {
    kotlin("jvm") version "2.3.20"
}

repositories {
    mavenCentral()
    maven("https://repo.papermc.io/repository/maven-public/")
}

dependencies {
    compileOnly(rootProject)
    compileOnly("io.papermc.paper:paper-api:1.21.11-R0.1-SNAPSHOT")
    compileOnly("org.jetbrains.kotlin:kotlin-stdlib")
}

kotlin {
    jvmToolchain(21)
}

tasks.jar {
    archiveFileName.set("example.jar")
}
```

模块不应用 Bukkit 插件插件，也不包含 `plugin.yml`。

## 3. 模块配置

`src/main/resources/config.yml`：

```yaml
id: example
name: "示例游戏"
enabled: true
main: jar
jar: "../example.jar"
entrypoint: "org.example.kagame.ExampleModuleProvider"
description: "Example managed game module."

game:
  display-name: "示例游戏"
  min-players: 1
  max-players: 16

maps:
  default:
    display-name: "默认地图"
    template: "example/default"

spectator:
  enabled: true
  mode: managed
```

`id` 必须与 `GameModule.id` 一致；`entrypoint` 必须实现 `GameModuleProvider`。

## 4. Provider

```kotlin
class ExampleModuleProvider : GameModuleProvider {
    override fun onLoad(context: GameModuleContext) {
        context.registerModule(ExampleGameModule(context))
        context.registerListener(ExampleListener(context.roomManager))
    }
}
```

Provider 只装配服务和注册入口，不保存某局玩家或计时器。

## 5. GameModule

```kotlin
class ExampleGameModule(
    private val context: GameModuleContext
) : GameModule {
    override val id = "example"
    override val displayName = "示例游戏"
    override val minPlayers = 1
    override val maxPlayers = 16

    override fun defaultDefinition() = GameDefinition(
        id = id,
        displayName = displayName,
        minPlayers = minPlayers,
        maxPlayers = maxPlayers,
        mapTemplates = listOf("example/default")
    )

    override fun createSession(room: GameRoom): GameSession {
        return ExampleGameSession(room, context.worldService)
    }
}
```

## 6. GameSession

```kotlin
class ExampleGameSession(
    override val room: GameRoom,
    private val worldService: TemporaryWorldService
) : GameSession {
    override fun onPrepare() {
        val worldName = "kgc_room_${room.id}_example"
        room.world = worldService.createRoomWorldFromDirectory(
            room.templateDirectory,
            worldName,
            allowFlatFallback = false
        )
    }

    override fun onPlayerJoin(player: Player) {
        val world = room.world ?: return
        player.teleport(world.spawnLocation)
    }
}
```

托管游戏应使用 `room.templateDirectory` 私有快照，并关闭 flat fallback。不要在 Provider 或 `onEnable` 创建世界。

## 7. Listener

```kotlin
class ExampleListener(
    private val roomManager: GameRoomManager
) : Listener {
    @EventHandler(ignoreCancelled = true)
    fun onMove(event: PlayerMoveEvent) {
        val room = roomManager.getPlayerRoom(event.player) ?: return
        val session = room.session as? ExampleGameSession ?: return
        session.handleMove(event.player, event.to)
    }
}
```

Listener 必须先按房间和 session 类型过滤，不能影响大厅或其他模块。

## 8. 构建和放置

```bash
bash ./gradlew :modules:example:jar
```

运行目录：

```text
plugins/KaGameCenter/modules/example.jar
plugins/KaGameCenter/modules/example/config.yml
plugins/KaGameCenter/maps/example/default/level.dat
plugins/KaGameCenter/maps/example/default/region/*.mca
```

首次加载会从 jar 释放缺失的配置和语言文件。

## 9. 最小验收

- 启动日志显示模块 `example` 已加载。
- `/kgc games` 能看到示例游戏。
- 管理面板能选择 `example` 和地图模板。
- 创建托管游戏后生成 yml 与私有地图目录。
- 玩家创建房间后只在首次准备阶段创建世界。
- 离开或关闭房间后世界被卸载删除，玩家状态恢复。
