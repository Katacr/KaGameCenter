## 模块文档

具体玩法的蓝图、配置、实现状态和测试记录位于 `modules/<module>/`。本 wiki 只描述 KaGameCenter 主插件契约。

## 核心规则

- 每个房间一个 `GameSession`。
- 单局玩家、实体、任务和计时器状态只存于 session。
- Listener 只负责找到房间并转发事件。
- Bukkit/Paper 玩家、实体和世界 API 只在主线程调用。
- 主插件只提供通用服务，模块保留自己的玩法含义。
- 模块通过 `GameModuleContext` 获取服务，不直接访问实现类。
- 不直接使用 NMS 或 PacketEvents wrapper。
- 离开、淘汰、结束、关闭和卸载都必须有明确清理路径。
