# 10 构建、部署与验收

更新时间：2026-07-13

## 构建环境

- Paper API `1.21.11`。
- JVM toolchain 21。
- 测试服 Paper `26.2`。
- 模块 compileOnly 依赖根项目和 Paper API。

## 构建命令

编译主插件与全部模块：

```bash
cd /home/plugins/KaGameCenter
sh ./gradlew compileKotlin
```

一键打包主插件与全部模块：

```bash
sh ./gradlew buildAll
```

主插件：

```bash
sh ./gradlew shadowJar
```

模块：

```bash
sh ./gradlew :modules:<module>:jar
```

产物：

```text
build/libs/KaGameCenter-1.0.0.jar
modules/<module>/build/libs/<module>-<version>.jar
```

各模块版本在 `gradle.properties` 中通过 `<module>Version` 独立声明。构建时版本会同时写入模块 JAR 内的 `config.yml`，并追加到产物文件名。

## Paper 26.2 目录

```text
/home/minecraft/Paper26.2/plugins/KaGameCenter-1.0.0.jar
/home/minecraft/Paper26.2/plugins/KaGameCenter/
  config.yml
  lang/
  menus/
  chest-menus/
  maps/<module>/<map>/
  modules/
    <module>-<version>.jar
    <module>/
      config.yml
      lang/
      games/
```

不要把模块 jar 放到 Paper `plugins/` 根目录。

## 部署

```bash
cp /home/plugins/KaGameCenter/build/libs/KaGameCenter-1.0.0.jar \
  /home/minecraft/Paper26.2/plugins/KaGameCenter-1.0.0.jar

cp /home/plugins/KaGameCenter/modules/<module>/build/libs/<module>-<version>.jar \
  /home/minecraft/Paper26.2/plugins/KaGameCenter/modules/<module>-<version>.jar

chown -R minecraft:minecraft /home/minecraft/Paper26.2/plugins/KaGameCenter*
```

默认配置和语言缺失时由 jar 自动释放。不要无条件覆盖管理员修改的配置、语言、菜单、地图或托管游戏包。

旧配置若仍填写 `../<module>.jar`，加载器会选择最新修改的 `<module>-<version>.jar`，并把实际版本和路径回写到模块配置。已明确填写版本化路径时视为版本锁定。

## 启动日志检查

确认：

- KaGameCenter 版本和 Minecraft 版本。
- 当前语言和数据库后端。
- 模块数量和 ID。
- 注册游戏列表。
- KaMenu、PlaceholderAPI、PacketEvents 状态。
- Velocity/Redis 状态。
- 没有模块 entrypoint/classloader 异常。
- 没有配置或语言文件权限错误。

## 模块加载失败

依次检查：

1. `modules/<module>.jar` 是否存在。
2. `modules/<module>/config.yml` 是否存在。
3. `id` 是否与 GameModule 一致。
4. `jar: ../<module>.jar` 是否正确。
5. `entrypoint` 完整类名是否正确。
6. `enabled` 是否为 true。
7. 文件所有者是否为 `minecraft:minecraft`。
8. required plugins 是否安装并启用。

## 地图失败

依次检查：

1. 公共模板 `level.dat` 和 `region/*.mca`。
2. 创建托管游戏后 `games/map/<localId>/` 是否存在。
3. 配置 runtime-map-template 和实际目录是否一致。
4. 目录权限。
5. 是否存在同名遗留 `kgc_edit_*` 或 `kgc_room_*` 世界。
6. 日志中的世界迁移和维度目录错误。

## 功能验收

### 房间

- 普通玩家可以创建房间并成为房主。
- 房间名称最多 16 字，ID 为四位且不重复。
- 房间列表模块显示名、地图、人数和状态正确。
- 重复加入/观战不会清空或重建房间。
- 正式玩家不能直接切换观战。
- 最后一名玩家/观战者离开后房间关闭。

### 世界

- 世界只在首次准备时创建。
- 使用托管游戏私有快照，而不是公共模板或 flat fallback。
- 观战者不能生成模板边界外新区块。
- 关闭后 Bukkit 世界和磁盘目录均删除。

### 玩家状态

- 加入前状态被保存。
- 正常离开、死亡淘汰、强制关房和停服都恢复。
- 不残留飞行、隐身、速度、药水、计分板或观战快捷栏。

### 多房间

- 同模块多个房间状态互不影响。
- 不同模块同时运行。
- 任务、实体、道具、聊天、名牌和统计不串房。

### 菜单与语言

- KaMenu 正常时打开主流程菜单。
- KaMenu 不可用时 fallback 不导致主插件启动失败。
- 普通玩家看不到管理员动作。
- zh_CN/en_US 和模块私有语言没有缺 key warning。

### 发包

- PacketEvents 缺失时 required 模块禁止开房或 optional 效果降级。
- 伪装移动后不现形。
- 发光移动后不丢失。
- 私有拾取只有合法角色获得。
- 离开和关房后视觉对象清理。
