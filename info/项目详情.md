# KaGameCenter 项目详情

更新时间：2026-07-16

## 项目定位

KaGameCenter 是面向 Paper 高版本服务器的小游戏运行平台。主插件长期常驻，小游戏以外置 jar 模块形式由主插件托管加载；同一服务器可以并发运行不同玩法以及多个同玩法房间。

- 源码目录：`/home/plugins/KaGameCenter`。
- 编译目标：Paper API `1.21.11`。
- Kotlin/JVM toolchain：21。
- 当前测试环境：Paper `26.2`。
- 测试服目录：`/home/minecraft/Paper26.2`。

## 架构边界

主插件负责：

- 模块发现、加载和卸载。
- 房间、玩家会话和生命周期。
- 临时世界、公共模板、私有地图快照和编辑会话。
- 玩家状态快照、观战、队伍、聊天和显示。
- 菜单路由、基础统计、发包视觉和名牌。
- Redis/Velocity 房间摘要、reservation 和 join intent。

小游戏模块负责：

- 玩法内部阶段和胜负规则。
- 角色、职业、技能、道具和局内状态。
- 模块级默认配置和模块私有语言。
- 托管游戏专属地图参数和编辑器。
- 玩法专属统计或数据库。

主插件不得包含某个小游戏的角色、道具或地图字段。所有单局数据必须属于对应 `GameSession`，不能保存在 provider、模块单例或全局集合中。

## 核心模型

- `GameModule`：一种玩法类型。
- `GameDefinition`：模块默认元数据、人数、地图、依赖和观战策略。
- `ManagedGameConfig`：管理员创建的具体游戏配置与私有地图快照。
- `GameRoom`：玩家创建的一次运行房间，拥有四位房间 ID。
- `GameSession`：一个房间的一局玩法实例。
- `PlayerSession`：玩家当前所在房间及参赛/观战身份。

房间状态：

```text
CREATED -> PREPARING -> WAITING -> COUNTDOWN -> RUNNING -> ENDING -> CLOSED
```

模块可以维护更细的内部阶段，但必须与房间生命周期正确衔接。

## 目录约定

```text
plugins/KaGameCenter/
  config.yml
  lang/
  menus/
  chest-menus/
  data/
  maps/<module>/<map>/
  modules/
    <module>-<version>.jar
    <module>/
      config.yml
      lang/
      games/
        game/<localId>.yml
        map/<localId>/
```

- 公共地图模板只作为托管游戏创建来源。
- 托管游戏编辑自己的私有地图快照，不修改公共模板。
- 房间运行时从私有快照复制临时世界，结束后卸载删除。
- 模块 jar 可以自动释放缺失的 `config.yml` 和 `lang/`；地图与游戏包不放进 jar。
- 模块版本在根 `gradle.properties` 中独立声明，并同时写入 jar 文件名、内嵌配置和 `GameModuleContext.version`。

## 模块边界

主插件只负责扫描、加载和卸载 `modules/` 中的外置模块。模块清单、完成度、玩法规则、配置字段与验收状态统一记录在各自 `modules/<module>/`，不在主插件文档复制。

## 已实现能力

### 房间与玩家

- 普通玩家创建房间，房主自动设置和转移。
- 四位房间 ID、房间名称、人数和状态展示。
- 加入、离开、观战、重复操作幂等和空房自动关闭。
- 玩家背包、位置、游戏模式、生命、经验等完整快照恢复。
- 模块临时运行状态的独立捕获与恢复。

### 世界与编辑

- 房间首次准备时创建临时世界，不在插件启用阶段创建。
- 从公共模板或托管游戏私有快照复制世界。
- 根据 region 数据计算模板边界并禁止无关区块生成。
- 通用石斧两点选区。
- 通用骨头连续采点，支持目标方块、脚下整数位置和保留朝向的精确位置。
- 管理员私有地图编辑会话、保存、恢复和临时世界清理。
- 编辑者跨世界离开或离线时自动恢复进入编辑前的状态；编辑世界人数归零后自动保存快照并关闭世界。
- 启动时清理符合 KaGameCenter 命名规则的遗留世界。

### 菜单与显示

- KaMenu YAML 为首选菜单渲染路径。
- 内置箱子菜单作为 fallback 和操作型 UI。
- Paper Dialog 作为最后主菜单兜底。
- 主菜单、创建房间、房间列表、详情、成员管理和托管游戏管理。
- 动态 `TYPE`：游戏、地图、房间行、玩家槽位和房间 Body 玩家列表。
- 默认 sidebar、BossBar、Title、ActionBar 和 Tab 信息。
- 通用彩色玩家头像、每行最多 5 个头像的 Sidebar Component，以及由 Session 提供状态快照的竞技 BossBar。
- 模块可接管自定义 sidebar 与 ActionBar。
- 玩家名牌前缀、后缀、颜色、可见性和碰撞规则。

### 队伍、聊天与观战

- 通用队伍注册、最少人数、轮转和比例分配。
- 普通聊天默认同房间同队；无队伍时回退房间聊天。
- `/a` 默认请求当前房间全部玩家和观战者聊天，玩法可通过 Session 路由进一步限制。
- `/g` 为本服全局聊天。
- 模块私有聊天格式和可选管理员旁听。
- `VANILLA` 与 `MANAGED` 两种观战模式。

### 数据与通用服务

- SQLite/MySQL 基础统计：场次、胜负、击杀、死亡、点数，以及按玩法隔离的可扩展计数指标。
- SQLite/MySQL 好友关系与申请，支持好友加入、观战、在线私聊和删除。
- 房间任务、实体归属、权重随机、结果记录、阶段计时和房间广播。
- 通用淘汰观战、房间资源作用域、托管地图点位和不重复出生点分配。
- 主插件与模块私有 i18n。
- 模块监听器、任务、聊天格式器、菜单数据源和类加载器卸载清理；加载中途失败时回滚已注册资源。
- 管理员可分别重载主配置、主语言、公共地图模板或指定托管模块；模块重载前会关闭所属房间并保存、关闭编辑会话。

### 发包与跨服

- PacketEvents 玩家方块/生物伪装、持续隐身、发光、私有掉落物和信标光柱。
- 名牌 Teams 包由 `PlayerNametagService` 管理。
- Redis 房间摘要、全局房间缓存、reservation 和 join intent。
- 跨服只同步房间摘要与加入事务，不同步局内实体、世界或 tick 状态。

## 菜单与命令

玩家命令：

```text
/kgc help
/kgc menu
/kgc chest [menuId]
/kgc stats [gameId]
/kgc friend <list|add|accept|deny|remove|join|spectate|msg> ...
/kgc games
/kgc rooms
/kgc create <gameId> [mapPath] [roomName]
/kgc join <roomId>
/kgc quickjoin <gameId>
/kgc leave
/a <message>
/g <message>
```

管理员命令：

```text
/kgc admin help
/kgc admin manage
/kgc admin maps ...
/kgc admin create <gameId>
/kgc admin start <roomId>
/kgc admin close <roomId>
/kgc admin stats
/kgc admin icon ...
/kgc admin packet ...
/kgc admin <module> ...
/kgc reload config
/kgc reload lang
/kgc reload map
/kgc reload model <moduleId|all>
```

`/kgc reload map` 只重新检查 `plugins/KaGameCenter/maps/` 公共模板目录。它不会扫描或修改 `modules/<module>/games/`，不会替换管理员已经完成的私有地图快照，也不会关闭或重建运行中的房间。`/kgc reload model` 才会关闭目标模块全部房间和编辑会话后卸载、加载模块。

权限：

- `kagamecenter.user`
- `kagamecenter.admin`
- `kagamecenter.chat.spy`

## API 演进原则

- 只有被多个模块复用且边界稳定的能力才进入主插件。
- 新能力优先通过 `GameModuleContext` 暴露。
- 模块不直接查找主插件内部实现类。
- 模块不直接使用 NMS 或 PacketEvents wrapper。
- API 发生破坏性变化时必须同步更新所有模块和 wiki。
- 是否存在某项 API 以当前源码和 wiki 为准，不以历史交接记录为准。

## 测试服

- systemd 单元：`minecraft-paper.service`。
- tmux socket：`minecraft-paper`。
- tmux session：`paper26.2`。
- 运行用户：`minecraft:minecraft`。

查看状态：

```bash
systemctl status minecraft-paper.service --no-pager
journalctl -u minecraft-paper.service -n 200 --no-pager
```

进入控制台：

```bash
sudo -u minecraft tmux -L minecraft-paper attach -t paper26.2
```

构建：

```bash
cd /home/plugins/KaGameCenter
bash ./gradlew buildAll
```

`buildAll` 同时生成主插件 Shadow JAR 与全部六个模块；单独构建模块使用 `bash ./gradlew :modules:<module>:jar`。

部署目录：

```text
/home/minecraft/Paper26.2/plugins/KaGameCenter-1.0.0.jar
/home/minecraft/Paper26.2/plugins/KaGameCenter/
```

复制后统一修正权限：

```bash
chown -R minecraft:minecraft /home/minecraft/Paper26.2/plugins/KaGameCenter*
```

不要默认覆盖管理员修改过的配置、语言、菜单、地图或托管游戏包。
