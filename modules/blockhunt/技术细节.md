# 方块躲猫猫模块技术细节

更新时间：2026-07-15

## 模块形态

`blockhunt` 是 KaGameCenter 的外置小游戏模块，编译产物为：

```text
modules/blockhunt/build/libs/blockhunt-<version>.jar
```

服务器运行目录预期为：

```text
plugins/KaGameCenter/modules/blockhunt-<version>.jar
plugins/KaGameCenter/modules/blockhunt/config.yml
plugins/KaGameCenter/modules/blockhunt/lang/
plugins/KaGameCenter/modules/blockhunt/games/game/<游戏名>.yml
plugins/KaGameCenter/modules/blockhunt/games/map/<游戏名>/
```

## 第一版已实现

- 模块配置读取：`BlockhuntConfigService`
- 模块注册：`BlockhuntModuleProvider` / `BlockhuntGameModule`
- KaMenu 外部配置入口管理编辑面板：`BlockhuntManagedGameEditor`
- 管理子命令：`/kgc admin blockhunt ...`
- 对局状态机：等待、开局倒计时、躲藏准备、运行、结算、关闭
- 自动分配两队：猎人、躲藏者
- 躲藏者方块伪装：通过主插件 `PacketDispatchService.disguisePlayerAsBlock`
- 可伪装方块白名单：由模块配置维护
- 双击潜行切换方块态/实体态；进入方块态时在当前位置或上半身位置写入当前伪装材质的真实方块，并保存原始 `BlockData`
- 方块态会额外生成 `Interaction` 命中盒；解锁、被抓、离开、房间结束或关闭时恢复原方块并移除命中盒
- 实体态玩家会设置真实隐身和无碰撞，并通过 `PacketDispatchService.disguisePlayerAsBlock` 让猎人和躲藏者本人看到移动方块伪装
- 猎人攻击玩家实体态、锁定态命中盒、锁定后的真实伪装方块，或雪球命中这些目标，都能计算抓捕
- 猎人发光道具同时影响实体态玩家和方块态真实方块位置
- 猎人近战抓捕、雪球命中抓捕
- 躲藏者被抓后可按配置转为猎人
- 倒计时/躲藏准备阶段中途加入的玩家会作为躲藏者加入，并立即分配伪装；运行阶段仍由主插件禁止普通加入
- 随机私有道具刷新：每 30 秒刷新一轮，猎人侧和躲藏者侧各产出 1 个道具；同侧玩家都能看到，但只有第一个触碰者获得
- 猎人道具：躲藏者发光、范围探测、雪球补给
- 躲藏者道具：猎人致盲、冻结猎人、放置假方块、自身隐身
- 最后 20 秒狂暴模式：躲藏者速度 III，猎人补充雪球
- 基础计分板与 ActionBar
- 胜负统计接入：胜利、失败、击杀、死亡
- 模块私有 i18n：`src/main/resources/lang/zh_CN.yml`、`en_US.yml`
- 阵营聊天：模块通过 `GameModuleContext.teamService` 注册 `hunter` 和 `hider` 队伍，开局分配身份时加入对应队伍，躲藏者被抓转猎人时切换到 `hunter`

## 聊天行为

Blockhunt 使用主插件通用聊天系统，不自行监听普通聊天。

- 普通聊天：默认发送给同阵营成员。
- `/a <消息>`：发送给当前房间所有玩家和观战者，猎人和躲藏者都可看到。
- `/g <消息>`：发送到服务器全局频道，可和房间外玩家互动。
- 聊天格式由模块私有语言文件定义：
  - `blockhunt.chat_team`
  - `blockhunt.chat_room`

队伍同步点：

- `BlockhuntGameSession` 创建时注册 `hunter`、`hider` 两个队伍。
- `assignRoles()` 分配身份后把玩家加入对应队伍。
- 倒计时/躲藏准备阶段中途加入的玩家作为躲藏者加入 `hider`。
- `caught-hider-becomes-hunter=true` 时，被抓躲藏者转换为猎人并加入 `hunter`。

## 自查修复记录

2026-06-20 自查后已修复：

- 离开房间、房间结束、躲藏者被抓时，统一恢复玩家飞行、旁观、速度、隐身、致盲和伪装视觉，避免残留到大厅。
- 方块态锁定实体坐标修正为直接使用解析后的锚点，避免 `BlockDisplay` / `Interaction` 因二次加偏移而错位。
- 雪球命中事件现在会按模块返回值取消，避免原版伤害/击退等副作用。
- 道具拾取增加角色校验，猎人只能触发猎人道具，躲藏者只能触发躲藏者道具。
- 每轮刷新新道具前清空旧的模块侧道具 ID，避免过期道具回调继续生效。
- 猎人发光道具会揭示方块态位置；该逻辑在 2026-06-22 改为针对真实锁定方块位置绘制轮廓。
- 倒计时/躲藏准备阶段加入的玩家会补入 `states`，避免无身份玩家进入游戏流程。

2026-06-22 锁定方块态实现调整：

- 方块态从固定 `BlockDisplay` 改为修改房间临时世界中的真实方块。
- `BlockhuntPlayerState` 保存 `lockedBlock`、`lockedOriginalBlockData`、`lockedHitbox`。
- 锁定时先清理实体态伪装，再写入伪装材质方块，并把真实玩家设为隐身、无碰撞、旁观移动。
- 解锁、被抓、离开房间、房间结束和关闭房间都会尝试恢复原始 `BlockData`。
- `BlockhuntListener` 新增左键真实方块判定和雪球命中真实方块判定，避免锁定态变成真实方块后无法被抓。
- 实体态伪装 viewer 包含躲藏者本人，因此第三人称下也能看到自己的方块伪装。

## 模块配置

主配置位于：

```text
plugins/KaGameCenter/modules/blockhunt/config.yml
```

关键字段：

```yaml
game:
  display-name: "方块躲猫猫"
  min-players: 2
  max-players: 16
  start-countdown-seconds: 5
  duration-seconds: 300
  hunter-release-seconds: 20
  frenzy-seconds: 20
  hunter-ratio: 0.25
  caught-hider-becomes-hunter: true
  hider-lock-double-sneak-ms: 450
  disguise-refresh-seconds: 45
  disguise-whitelist:
    - GRASS_BLOCK
    - DIRT
    - STONE
    - OAK_PLANKS
    - OAK_LEAVES

items:
  refresh-seconds: 30
  pickup-duration-seconds: 25
  pickup-scale: 1.5
  max-active-per-role: 1
  hunter-snowballs: 16
  hunter-glow-seconds: 5
  hunter-probe-radius: 10
  hunter-probe-uses: 3
  hider-blind-seconds: 5
  hider-freeze-seconds: 5
  hider-fake-block-seconds: 30
  hider-invisible-seconds: 5

maps:
  default:
    display-name: "默认地图"
    template: "blockhunt/default"
```

## 托管游戏配置

管理员通过主插件管理面板创建托管游戏后，配置文件位于：

```text
plugins/KaGameCenter/modules/blockhunt/games/game/<游戏名>.yml
```

模块私有参数写入 `blockhunt` 节点：

```yaml
blockhunt:
  lobby:
    x: 0.0
    y: 80.0
    z: 0.0
    yaw: 0.0
    pitch: 0.0
  hunter-spawn:
    x: 10.0
    y: 80.0
    z: 10.0
    yaw: 0.0
    pitch: 0.0
  hider-spawn:
    x: 20.0
    y: 80.0
    z: 20.0

    pitch: 0.0

      y: 60
      z: -50

      y: 120
      z: 50
  item-spawns:
    - id: item_1
      point:
        x: 5.0
        y: 80.0
        z: 5.0
```

## 管理入口

主插件管理面板：

- `/kgc admin manage`
- 选择模块 `方块躲猫猫`
- 选择地图模板
- 输入游戏名创建托管游戏
- 打开该托管游戏编辑器

模块命令：

```text
/kgc admin blockhunt reload
/kgc admin blockhunt list
/kgc admin blockhunt edit <游戏ID>
/kgc admin blockhunt openworld <游戏ID>
/kgc admin blockhunt setlobby
/kgc admin blockhunt sethunter
/kgc admin blockhunt sethider
/kgc admin blockhunt setregion
/kgc admin blockhunt additem
/kgc admin blockhunt removeitem <编号>
/kgc admin blockhunt save
/kgc admin blockhunt close
/kgc admin blockhunt preview
```

`edit` 可按全局 ID 或本地 ID 重新打开标准托管编辑菜单；`openworld` 在菜单渲染不可用时可直接进入私有编辑世界。其余点位、区域、保存和预览命令复用 `BlockhuntManagedGameEditor`，并要求玩家已进入对应私有编辑世界。

## 当前限制

- 第一版不提供伪装选择菜单，躲藏者会根据脚下方块或白名单候选随机伪装。
- 道具刷新点不区分猎人/躲藏者专属点。每轮从可用刷新点中随机选点，猎人道具和躲藏者道具各 1 个。
- `max-active-per-role` 第一版实际作为“是否启用道具刷新”的开关和兼容字段使用；当前逻辑固定每轮双方各 1 个。
- 道具拾取为 PacketEvents 私有 ItemDisplay，不是真实世界掉落物。每个可见玩家客户端各有一份视觉实体，但模块侧使用同一个道具 ID 控制，先触碰者获得，后触碰者无效。
- 躲藏者进入锁定方块态后，本体处于旁观移动状态，不能拾取道具，避免“方块留在原地、灵魂出窍吃道具”的玩法漏洞。
- 假方块当前是服务器真实 `BlockDisplay` 临时实体，所有玩家可见；后续如需单玩家可见，应下沉到 `PacketDispatchService`。
- 锁定方块态的发光当前通过 `showBlockGlow` 在锁定方块位置显示轮廓；实体态发光仍通过 `showPlayerGlow`。
- 方块伪装依赖 `PacketDispatchService` 的持续刷新，目前刷新周期由 `disguise-refresh-seconds` 控制。
- 冻结猎人道具会记录猎人的完整 `Location`，在持续期间回拉位置和视角。
- 躲藏者隐身道具在实体态使用原版隐身效果并暂停 PacketEvents 方块伪装刷新；方块态当前不隐藏真实地图方块，因为直接隐藏真实方块会涉及恢复原方块/再次写入伪装方块的冲突策略。
- 猎人发光道具会在锁定方块态的真实方块位置绘制方块轮廓。
- BossBar 使用主插件通用显示，模块自定义了计分板和 ActionBar。

## 测试建议

1. 构建主插件与模块：

```text
sh ./gradlew shadowJar :modules:blockhunt:jar
```

2. 复制到测试服：

```text
build/libs/KaGameCenter-1.0.0.jar
modules/blockhunt/build/libs/blockhunt-<version>.jar
src/main/resources/modules/blockhunt/config.yml
```

3. 准备公共模板：

```text
plugins/KaGameCenter/maps/blockhunt/default/
```

要求包含 `level.dat` 和 `region/*.mca`。

4. 开服后创建托管游戏并进入编辑器。
5. 设置大厅、猎人出生点、躲藏者出生点、游戏区域、道具刷新点。
6. 创建房间并至少两名玩家开始游戏。
