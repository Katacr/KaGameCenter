# TNT Wars 模块技术细节

更新时间：2026-07-13

## 模块形态

`tntwars` 是 KaGameCenter 的外置小游戏模块，编译产物为：

```text
modules/tntwars/build/libs/tntwars-<version>.jar
```

运行目录预期：

```text
plugins/KaGameCenter/modules/tntwars-<version>.jar
plugins/KaGameCenter/modules/tntwars/config.yml
plugins/KaGameCenter/modules/tntwars/lang/
plugins/KaGameCenter/modules/tntwars/games/game/<游戏名>.yml
plugins/KaGameCenter/modules/tntwars/games/map/<游戏名>/
```

## 第一版已实现

- Gradle 子模块：`modules:tntwars`
- 模块配置：`TntWarsConfigService`
- 模块注册：`TntWarsModuleProvider` / `TntWarsGameModule`
- 模块私有语言：`src/main/resources/lang/zh_CN.yml`、`en_US.yml`
- 模块私有聊天格式：
  - 普通聊天按主插件队伍聊天分发
  - `/a` 房间全员频道
  - `/g` 服务器全局频道
- 托管游戏编辑器：`TntWarsManagedGameEditor`
- 对局状态机：
  - `WAITING`
  - `COUNTDOWN`
  - `RUNNING`
  - `RESULT`
  - `CLOSING`
- 自动注册并分配两队：
  - `red`
  - `blue`
- 地图运行：
  - 使用托管游戏私有地图快照创建临时房间世界
  - 结束后由主插件卸载删除临时世界
- 管理编辑器字段：
  - 大厅点
  - 观战点
  - 红队出生点
  - 蓝队出生点
  - 游戏区域
  - 淘汰高度
- 第一版道具：
  - TNT 矿车
  - 普通 TNT
  - 远距离 TNT
  - 苦力怕
  - 火球
  - TNT 弓
  - TNT 雨
  - 苦力怕雨
  - 火球雨
- 道具实现：
  - 使用 `PersistentDataContainer` 标记 `tntwars_item`
  - 按配置权重定时给所有存活玩家发放随机道具
  - 监听 `PlayerInteractEvent`
  - TNT 弓监听 `EntityShootBowEvent` 和 `ProjectileHitEvent`
  - 使用后按配置消耗
  - 生成爆炸实体时通过主插件 `RoomEntityOwnershipService` 记录 owner
- 淘汰逻辑：
  - 掉到 `void-y` 以下淘汰
  - 原版死亡事件进入 `onPlayerDeath`
  - 运行中离开按淘汰处理
- 胜负逻辑：
  - 红队全灭，蓝队胜利
  - 蓝队全灭，红队胜利
  - 双方同时全灭或时间结束，无胜者
- 统计：
  - 虚空淘汰会按最近一次敌方爆炸来源记录 kill/death
  - 原版死亡仍由主插件 `GamePlayerListener` 记录，避免重复
  - 结算记录 win/loss
- 显示：
  - 开局 Title
  - 淘汰消息
  - 结算 Title
  - 自定义 Scoreboard
  - 道具发放 ActionBar

## 代码结构

```text
TntWarsModuleProvider.kt       # 模块入口，注册模块、编辑器、监听器、聊天格式
TntWarsGameModule.kt           # GameModule 实现
TntWarsGameSession.kt          # 对局运行状态机和玩法逻辑
TntWarsListener.kt             # Bukkit 事件转发到当前房间 session
TntWarsConfigService.kt        # 模块配置和托管游戏配置读写
TntWarsModels.kt               # 配置、队伍、道具、玩家状态模型
TntWarsManagedGameEditor.kt    # KaMenu 外部配置入口管理编辑器
```

## 模块配置

模块默认配置位于：

```text
plugins/KaGameCenter/modules/tntwars/config.yml
```

关键字段：

```yaml
game:
  display-name: "TNT Wars"
  min-players: 2
  max-players: 16
  start-countdown-seconds: 5
  duration-seconds: 600
  result-display-seconds: 10
  close-delay-seconds: 6
  void-y: -70.0
  item-interval-seconds: 10
  initial-item-delay-seconds: 10
  resistance-amplifier: 25
  glowing-enabled: true

items:
  give-per-player: 1
  consume-on-use: true
  pool:
    tnt:
      enabled: true
      weight: 2
      fuse-ticks: 50
      velocity: 1.2
      power: 4.0
    long_tnt:
      enabled: true
      weight: 2
      fuse-ticks: 50
      velocity: 2.0
      power: 4.0
    fireball:
      enabled: true
      weight: 5
      velocity: 1.5
      power: 5
    tnt_bow:
      enabled: true
      weight: 2
      fuse-ticks: 80
      power: 4.0
    tnt_rain:
      enabled: true
      weight: 1
      duration-seconds: 10
      drops-per-second: 4
      power: 4.0
```

- Fireball：5
- TNT Minecart：3
- Creeper：3
- TNT：2
- TNT Bow：2
- Long-Way TNT：2
- TNT Rain：1
- Creeper Rain：1
- Fireball Rain：1

## 托管游戏配置

管理员通过 `/kgc admin manage` 创建托管游戏后，配置文件位于：

```text
plugins/KaGameCenter/modules/tntwars/games/game/<游戏名>.yml
```

模块私有字段：

```yaml
tntwars:
  lobby: {}
  spectator-spawn: {}
  team-spawns:
    red: {}
    blue: {}
  play-region: {}
  void-y: -70.0
```

坐标不保存世界名。房间运行时创建随机临时世界，并使用相同绝对坐标。

## 编辑流程

1. `/kgc admin manage`
2. 选择模块 `TNT Wars`
3. 选择公共地图模板
4. 输入托管游戏名
5. 打开模块编辑器
6. 点击 `打开编辑世界`
7. 设置大厅、观战点、红蓝出生点、游戏区域、淘汰高度
8. 保存地图快照
9. 玩家创建房间并开始测试

## 当前限制

- 击杀归因基于最近一次敌方爆炸影响，属于第一版近似实现。
- 目前没有单独的模块 admin 指令，主要通过 `/kgc admin manage` 的 UI 编辑。
- TNT 雨使用游戏区域随机落点，要求管理员正确设置 `play-region`。
- 地图必须是私有临时世界运行，不能在公共模板世界中开局。
- 爆炸强度和实体数量需要在测试服做压力测试后再调默认值。

## 复用的 GameCenter 基底

TNT Wars 当前已接入主插件通用基底：

- `RoomTaskService`
  - 用于追踪 TNT 雨、苦力怕雨、火球雨等房间循环任务。
  - `onClose()` 中按 `room.id` 统一取消任务。
- `RoomEntityOwnershipService`
  - 用于记录 TNT、火球、苦力怕、TNT 矿车、TNT 弓箭矢等实体 owner。
  - 爆炸和弹体命中时校验 `record.roomId`，避免多房间串台。
- `WeightedPool` / `WeightedRewardDistributor`
  - 用于定时给存活玩家发放随机道具。
  - 模块只定义道具类型、权重和发放效果。
